# Leave Manager

Fill and track AIIMS Bhopal leave forms: CL/RH, leave applications, conferences, examinership, departure and joining reports, TA and food bills, and cancellation letters.

Open the app at https://shaktipathology.github.io/leave-manager/ and sign in. Your profile, leave and forms are stored in a private Firebase database that only your sign-in can read; this repository holds only the app itself.
